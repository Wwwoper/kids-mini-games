# Мини-игры для детей 4–6 лет

Семь офлайн-игр в браузере:

- «Третий лишний»;
- «Что пропало?»;
- «Что появилось?»;
- «Котик и щенок»;
- «Сколько?»;
- «Продолжи узор»;
- «Что сначала, что потом?».

**Играть:** `https://USERNAME.github.io/kids-mini-games/`

## Правила игр

- **Третий лишний.** Среди трёх картинок нужно найти ту, что не подходит к двум другим. После верного ответа голос объясняет почему.
- **Что пропало?** Ребёнок запоминает картинки, нажимает «Запомнил!», одна картинка пропадает — нужно выбрать её из вариантов.
- **Что появилось?** Ребёнок запоминает картинки, затем среди них появляется одна новая — нужно её найти.
- **Котик и щенок.** Крестики-нолики 3×3: вдвоём на одном устройстве или с компьютером (три уровня сложности).
- **Сколько?** Посчитать картинки и найти цифру. На высоком уровне нужно ещё и по цифре найти группу с таким же числом картинок.
- **Продолжи узор.** Узор из картинок (например, яблоко, груша, яблоко, груша…) — выбрать, что будет дальше.
- **Что сначала, что потом?** Расставить картинки по порядку: росток и цветок, яйцо и курица, утро и ночь.

## Возможности

- Работа без интернета.
- Отсутствие регистрации, аналитики и рекламы. Статистика хранится только на устройстве.
- Три уровня сложности в каждой игре.
- Адаптивная сложность: после трёх верных ответов подряд приложение ненавязчиво предлагает уровень выше, после двух ошибок подряд — ниже.
- Наклейка за каждые пять правильных раундов и страница «Мои звёздочки».
- Экран «Для взрослых» (защищён вопросом на умножение): раунды за день, процент верных ответов, частые ошибки, сброс прогресса, отключение подсказок о смене уровня.
- Голосовые инструкции через Web Speech API.
- Поддержка телефона, планшета и компьютера.

## Установка на телефон

Откройте ссылку в Safari или Chrome и выберите пункт «Добавить на главный экран».

## Для разработчиков

Приложение — статический сайт на ES-модулях, без сборки и без `package.json`.
ES-модули не работают через `file://`, поэтому локально запускайте HTTP-сервер:

```bash
npx serve .
# или: python3 -m http.server 8000
```

- `docs/CONTRIBUTING.md` — как добавить игру или раунд.
- `docs/CONTENT.md` — формат JSON-файлов контента.
- `tests/generator.html` — тесты инвариантов (откройте через HTTP-сервер).
