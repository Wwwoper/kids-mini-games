# Формат контента

Контент хранится отдельно от логики. Чтобы добавить раунд или уровень, JavaScript менять не нужно.

## Карточки: `shared/js/content/cards.js`

Единый список `POOL`. Ключ — латинский `id`, значение — русское название (`label`, его читает голос и экранный диктор) и `emoji`. Правила: `id` уникален, `emoji` не повторяется, `label` непустой. Новая карточка сразу появляется во всех играх.

```javascript
rabbit: { label: 'заяц', emoji: '🐰' },
```

## «Третий лишний»: `shared/content/rounds-tretiy.json`

```json
{
  "easy":     [ { "cards": ["apple", "pear"], "odd": "bus", "explain": "Яблоко и груша — фрукты, а автобус — транспорт." } ],
  "hard":     [],
  "veryHard": []
}
```

- `cards` — ровно два `id` из `POOL`, они не повторяются.
- `odd` — `id` лишней картинки, не входит в `cards`.
- `explain` — непустое объяснение, его читает голос.

`validateRound(round, pool)` проверяет это. Ошибочный раунд пропускается, причина пишется в консоль. Если файл не загрузился, игра показывает «Позовите взрослого».

## «Что пропало?», «Что появилось?», «Котик и щенок»: `shared/content/levels-memory.json`

| Игра | Поля уровня |
|---|---|
| `chto-propalo` | `N` карточек, `M` вариантов, `memCols`, `ansCols`, `optCols`, `shuffle`, `hint` |
| `chto-poyavilos` | `N` карточек, `memCols`, `finCols`, `shuffle`, `hint` |
| `tic-tac-toe` | `strategy` (`simple` или `minimax`), `mistakeChance`, `computerFirst`, `levelHint`, `hint`; блок `together` — тексты режима «вдвоём» |

## «Сколько?»: `shared/content/skolko.json`

- `items` — `id` карточек из `POOL`, которые можно считать.
- `levels.<уровень>`: `min`, `max` (диапазон количества), `options` (число вариантов), `mode` (`count-to-digit` — найти цифру, `digit-to-count` — найти группу картинок, `mixed` — случайно то и другое), `hint`.
- Правило: `max - min + 1 >= options`.

## «Продолжи узор»: `shared/content/uzor.json`

`levels.<уровень>`: `options`, `hint`, `patterns` — список `{ "p": "AAB", "shown": 5 }`. Буква — одна картинка, `shown` — сколько элементов показано. Ответ — элемент с номером `shown`. Условие: `shown >= p.length`, чтобы был виден полный период.

## «Что сначала, что потом?»: `shared/content/posledovatelnost.json`

- `levels.<уровень>`: `steps` (сколько картинок расставлять, не больше длины самых коротких последовательностей), `hint`.
- `sequences`: список `{ "title": "Растение", "steps": [{ "image": "../shared/img/sequences/plant-seed.svg", "label": "семечко" }, …] }`.
- `image` — путь к локальному SVG в `shared/img/sequences/`; внешние URL не допускаются.
- `label` — короткое название, используемое для доступного имени карточки и голосового сопровождения.
- Правила: не меньше двух шагов, `image` и `label` непустые, путь к иллюстрации локальный и уникальный внутри последовательности (`validateSequence`).

Иллюстрации в `shared/img/sequences/` созданы для проекта и распространяются вместе с ним по лицензии MIT.

## Прогресс ребёнка

Хранится только в `localStorage` под ключом `kmg-progress` (по дням, по играм, последние пять ответов, наклейки). Структура описана и нормализуется в `shared/js/logic/progress-model.js`. Кнопка «Сбросить прогресс» на экране взрослого очищает всё, кроме настройки подсказок.
