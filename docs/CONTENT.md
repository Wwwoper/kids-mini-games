# Формат контента

Контент хранится отдельно от логики. Чтобы добавить раунд или уровень, JavaScript менять не нужно.

## Карточки: `shared/js/content/cards.js`

Единый список `POOL`. Ключ — латинский `id`, значение — русское название (`label`, его читает голос и экранный диктор) и `emoji`.

```javascript
rabbit: { label: 'заяц', emoji: '🐰' },
```

Правила: `id` уникален, `emoji` не повторяется, `label` непустой. Новая карточка сразу появляется во всех играх.

## Раунды «Третий лишний»: `shared/content/rounds-tretiy.json`

```json
{
  "easy":     [ { "cards": ["apple", "pear"], "odd": "bus", "explain": "Яблоко и груша — фрукты, а автобус — транспорт." } ],
  "hard":     [],
  "veryHard": []
}
```

- `cards` — ровно два `id` из `POOL`, они не повторяются.
- `odd` — `id` лишней картинки, не входит в `cards`.
- `explain` — непустое объяснение, его читает голос.

### Как добавить раунд

1. Откройте `shared/content/rounds-tretiy.json`.
2. Добавьте объект в массив нужного уровня.
3. Откройте `tests/generator.html` через HTTP-сервер и убедитесь, что всё зелёное.

### Валидация

`validateRound(round, pool)` проверяет существование всех `id`, ровно одну лишнюю карточку и непустое `explain`. Ошибочный раунд пропускается, причина пишется в консоль. Если файл не загрузился, игра показывает сообщение «Позовите взрослого».

## Уровни: `shared/content/levels-memory.json`

| Игра | Поля уровня |
|---|---|
| `chto-propalo` | `N` карточек, `M` вариантов, `memCols`, `ansCols`, `optCols`, `shuffle`, `hint` |
| `chto-poyavilos` | `N` карточек, `memCols`, `finCols`, `shuffle`, `hint` |
| `tic-tac-toe` | `strategy` (`simple` или `minimax`), `mistakeChance`, `computerFirst`, `levelHint`, `hint`; блок `together` — тексты режима «вдвоём» |

Идентификаторы уровней: `easy`, `hard`, `veryHard`.
