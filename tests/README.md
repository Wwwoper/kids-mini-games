# Тесты инвариантов

1. Запустите HTTP-сервер в корне проекта (`npx serve .` или `python3 -m http.server`).
2. Откройте `http://localhost:<порт>/tests/generator.html`.
3. Страница выполнит проверки в браузере и покажет отчёт. Заголовок вкладки начинается с `PASS` или `FAIL`.

Логика проверок находится в `tests/suite.js`. Она не использует DOM, поэтому её можно запустить и в Node (нужен временный `package.json` с `"type": "module"` — в проект его не добавляйте).

Что проверяется:

- «Третий лишний»: ровно один правильный `id`, позиция ответа не фиксирована, `explain` непустой, валидатор ловит ошибки.
- «Что пропало?»: `answer ∈ S`, `options` содержит ответ один раз и не содержит других карт из `S`, `options.length === M`, при `shuffle: false` ровно один `null`.
- «Что появилось?»: новый `id` не из `S`, `finalItems.length === N + 1`, `S ⊆ finalItems`, ровно один новый; при `shuffle: false` порядок старых карточек сохраняется, а новая вставляется в случайную позицию.
- «Котик и щенок»: `result()` на всех линиях, `bestMinimaxMove()` не проигрывает ни в одной из сотен партий.
- «Сколько?»: число вариантов, единственный верный вариант, диапазон, режим `mixed` даёт оба типа заданий.
- «Продолжи узор»: узор строго периодичен, разные буквы — разные картинки, ответ однозначен.
- «Что сначала, что потом?»: шаги идут подряд из исходной последовательности, перемешанный порядок никогда не совпадает с верным.
- Прогресс и адаптивная сложность: правила «3 верных → вверх», «2 ошибки → вниз», не больше пяти ответов в истории, топ-3 ошибок, защита от испорченных данных в `localStorage`.

Дополнительная проверка жизненного цикла service worker запускается в Node.js:

```bash
node tests/service-worker.test.mjs
```

Она проверяет, что фоновое обновление кэша связано с `event.waitUntil()` и запись ответа завершается до окончания события fetch.

Статическая проверка структуры меню запускается отдельно:

```bash
node tests/menu-markup.test.mjs
```

Проверка клавиатурного фокуса в игре последовательностей запускается отдельно:

```bash
node tests/sequence-focus.test.mjs
```

Она проверяет, что после правильного выбора фокус переносится на следующую ожидаемую карточку, а после завершения раунда — на кнопку следующего раунда.

Проверка оформления главного меню запускается отдельно:

```bash
node --test tests/menu-design.test.mjs
```

Она проверяет наличие всех семи игр, иллюстрированных превью, адаптивную сетку и заметный клавиатурный фокус без синей рамки.
